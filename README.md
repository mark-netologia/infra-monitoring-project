# infra-monitoring-project
Учебный DevOps-проект для мониторинга доступности API,
анализа HTTP-логов и развёртывания контейнеризированного сервиса.

В проекте используются:
- Bash — мониторинг API и анализ логов.
- Docker Compose — запуск сервисов.
- Nginx — проксирование HTTP-запросов.
- GitHub Actions — автоматическая проверка Bash-скриптов.
- Wireshark — анализ сетевого трафика.

## Bash-скрипты

### Проверка доступности API

Скрипт `check_api.sh` отправляет HTTP-запрос по указанному URL
и проверяет код ответа сервера.

Пример запуска:

```bash
./check_api.sh https://httpbin.org/status/200
```

При коде 200 скрипт сообщает, что API доступен,
и завершается с кодом 0.

При ошибке возвращает код завершения 1.

### Анализ логов

Скрипт `analyze_log.sh` генерирует тестовый файл access.log
и анализирует HTTP-запросы.

Пример запуска:

```bash
./analyze_log.sh
```

## Безопасная передача проекта на сервер (SSH/SCP)

SSH используется для защищённого подключения к удалённому серверу,
а SCP — для безопасной передачи файлов через SSH.

### Генерация SSH-ключей

Для создания пары SSH-ключей используется команда:

```bash
ssh-keygen -t ed25519
```

Команда создаёт приватный и публичный ключи.
Приватный ключ должен храниться в секрете.

### Копирование публичного ключа на сервер

```bash
ssh-copy-id user@server.example.com
```

Команда добавляет публичный ключ в список разрешённых
ключей удалённого пользователя.

### Создание архива проекта

Перед передачей файлы проекта упаковываются в архив.
Команда выполняется из корневой папки проекта:

```bash
tar -czf infra-monitoring-project.tar.gz \
  --exclude='.git' \
  --exclude='access.log' \
  -C .. infra-monitoring-project
```

Параметр `-czf` создаёт сжатый архив формата `.tar.gz`.
Параметр `--exclude` исключает ненужные файлы и каталоги.

### Передача архива через SCP

```bash
scp infra-monitoring-project.tar.gz user@server.example.com:/home/user/
```

Команда передаёт архив с локального компьютера
в домашнюю директорию пользователя на удалённом сервере.

### Подключение к удалённому серверу

```bash
ssh user@server.example.com
```

После успешной аутентификации пользователь получает доступ
к командной строке удалённого сервера.

### Распаковка архива на сервере

```bash
tar -xzf infra-monitoring-project.tar.gz
```

В результате на сервере появится каталог с файлами проекта.

Адрес `server.example.com` и пользователь `user` приведены
для примера. При реальном развёртывании их необходимо заменить
на данные удалённого сервера.
